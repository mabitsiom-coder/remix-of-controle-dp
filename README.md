# Remix of CONTROLE DP

Você é um arquiteto de software especialista em Departamento Pessoal, eSocial, SST, gestão operacional, Business Intelligence e UX.

Sua missão é desenvolver um sistema SaaS extremamente moderno para gerenciamento completo do Departamento Pessoal de um escritório de contabilidade.

O sistema deve funcionar como um verdadeiro Centro de Controle Operacional do DP.

O objetivo é reduzir erros operacionais, controlar obrigações legais, acompanhar produtividade, organizar rotinas, armazenar particularidades dos clientes e fornecer indicadores gerenciais em tempo real.

O sistema deve possuir interface moderna semelhante ao Notion, Monday.com, ClickUp e Power BI.
